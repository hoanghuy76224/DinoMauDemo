# DinoMauDemo

Bản demo các mẫu thiệp của Dino Wedding Service, tên và địa chỉ là giả, ảnh dùng ảnh Phúc Giang (đã xin phép) và ảnh stock Unsplash.
Mỗi thư mục `mau-*` là một project Cloudflare Pages riêng (root directory = tên thư mục), domain `<thư-mục>.khunglongcon.com`.
Dữ liệu RSVP/lời chúc của demo nằm ở các collection `demo_*` trên Firestore, tách khỏi dữ liệu khách thật.
